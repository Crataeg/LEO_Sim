# LEO_Sim

This repository is an archival upload target for 卫星论文、LEO 星座、轨道覆盖、链路预算、切换、波束、NTN 等 LEO 研究资料.

This upload run follows a complete-archive principle: copy materials into the repository, keep original structures where possible, and do not clean, delete, deduplicate, rename, rewrite, compress, or exclude old/intermediate/cache/large/archive files merely because they are messy or duplicated.

The main copied materials are under collected_original_structure/. Materials that may be related but cannot be confidently assigned are under uncertain_related_materials/. Automatically generated indexes, copy logs, and file trees are under docs_auto_generated/.

The copied scripts, simulations, manuscript assets, logs, tables, figures, compressed packages, and intermediate outputs are preserved as archival material. They are not guaranteed to be reorganized into a one-command reproducible project state.

Required reports for this upload run:

- UPLOAD_MANIFEST.csv: per-file archive manifest.
- SOURCE_PATHS.md: scanned and copied source roots.
- SENSITIVE_SCAN_REPORT.md: read-only sensitive keyword scan before push.
- PUSH_LOG.md: Git/Git LFS/add/commit/push log.
- docs_auto_generated/file_tree.txt: generated repository file tree.
