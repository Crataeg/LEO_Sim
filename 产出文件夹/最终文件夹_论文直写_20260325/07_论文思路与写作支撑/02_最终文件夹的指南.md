# 最终文件夹的指南

## 先看这份指南的目的

这份最终文件夹不是单纯的“备份”，而是一个可以直接支持论文写作的工作面。

你可以把它理解成：
- `工程代码`
- `知识资产`
- `论文依据`
- `运行结果`
- `写作提纲`

全部已经按写论文的顺序整理好了。

## 最推荐的阅读顺序

### 第一步：先看总体思路

看：
- `07_论文思路与写作支撑/总体研究思路.md`
- `07_论文思路与写作支撑/问题解决总报告.md`
- `07_论文思路与写作支撑/IEICE方向初步反思.md`

作用：
- 帮你先定文章主线
- 避免一上来就陷进代码细节

### 第二步：再看行级写作大纲

看：
- `07_论文思路与写作支撑/01_基于目前工程的行级写作大纲.md`

作用：
- 告诉你每个章节该写什么
- 告诉你每段内容对应哪些代码和结果

### 第三步：写方法时看代码解析

看：
- `03_代码行级技术解析/卫星通信相关技术代码级报告_行级对应.md`
- `07_论文思路与写作支撑/代码行级技术与研究思路对应.md`

作用：
- 从“代码实现”翻译成“论文方法”

### 第四步：写相关工作和现实依据时看知识资产

看：
- `09_知识资产与写作依据`
- `05_IEICE论文与模板`
- `04_开源数据与选择评估`

作用：
- 提供综述、引用和背景支撑

### 第五步：写实验结果时看本轮 MATLAB 实跑结果

看：
- `10_本轮MATLAB运行结果/outputs_v7`
- `10_本轮MATLAB运行结果/dataset_stft_r2021a_exports`
- `11_运行环境与依赖`

作用：
- 提供本轮真实可写入的结果

## 当前最重要的现实结论

### 工程已经能跑到哪一步

当前：
- MATLAB 已可运行
- 主链可跑
- `InfoGAN + GA` 最劣搜索可跑
- STFT 数据集生成和 LeNet 训练可跑
- confusion matrix / keyframes 可导出

### 工程还卡在哪一步

当前不再卡在 `ga`。

这在：
- `11_运行环境与依赖/function_availability_20260327.txt`

里有明确证据：
- `ga => 2`

当前真正需要注意的是：
- 工程完整运行后，Dashboard / 3D Viewer 在批处理环境下可能报计时器类提示
- 但不影响 `outputs_v7` 和识别导出图生成

## 最后建议

如果你现在就开始写论文，最稳的做法是：

1. 用 `07_论文思路与写作支撑/01_基于目前工程的行级写作大纲.md` 开写
2. 用 `10_本轮MATLAB运行结果` 写结果
3. 用 `03_代码行级技术解析` 写方法
4. 用 `04 + 05 + 09` 写背景和依据
5. 在讨论中诚实写出：
   - 当前平台依赖 `Global Optimization Toolbox`
   - 当前结果是在关闭 3D Viewer 的非交互环境中跑出的
   - 但主链和最劣搜索已经闭环

这样论文会最稳。
