# 数学公式加强版写作包

这个包的目的不是重复普通提纲，而是把当前工程提升成更接近 `IEICE Transactions on Communications` 风格的数学化写作框架。

## 包含内容

- `01_IEICE相关论文公式风格分析.md`
- `02_工程数学建模与公式推导总表.md`
- `03_数学公式加强版写作大纲.md`
- `04_章节-公式-代码映射表.md`

## 推荐使用顺序

1. 先看 `01_IEICE相关论文公式风格分析.md`
2. 再看 `02_工程数学建模与公式推导总表.md`
3. 然后按 `03_数学公式加强版写作大纲.md` 开写
4. 写正文时随时查 `04_章节-公式-代码映射表.md`

## 这一包的核心定位

它要把我们的工程从：
- “平台说明 + 工程结果”

提升到：
- “系统模型 + 链路/干扰/优化数学表达 + 工程验证”
